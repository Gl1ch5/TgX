# TeleX — Стена каналов (Liquid Glass Stream Pro)

Легкое, красивое и быстрое веб-приложение для чтения всех ваших подписок Telegram в виде единого нативного потока (Стена каналов) с поддержкой официальных векторных обоев Telegram (`t.me/bg/...`), нижней плавающей стеклянной панелью управления (iOS Perfect Glass Dock), нативным окном настроек и 3D-иконками **Liquid Glass**.

---

## ⚡ Ключевые возможности

- ✈️ **Оригинальный брендинг TeleX**:
  - Фирменная эмблема Telegram (синий круговой самолётик).
  - Лаконичное название **TeleX** без лишнего текста и перегруженных панелей.
- 🪟 **Плавающая стеклянная панель (iOS Perfect Glass Dock)**:
  - Нижняя панель по формуле стекла iOS Dark Mode (`blur(45px) saturate(220%)`).
  - Быстрые разделы: **Стена**, **Каналы**, **Обои**, **Профиль**.
- ⚙️ **Полноценное нативное окно настроек**:
  - Открывается отдельным аккуратным окном без iframe'ов и обрезок.
  - Отображает реальные данные пользователя, номер телефона, юзернейм, Premium статус и разделы настроек.
- 🎨 **Система официальных обоев Telegram (Wallpaper Engine)**:
  - 9 оригинальных векторных SVG-паттернов Telegram (`t.me/bg/...`) с чёткими белыми контурами + глубокий OLED Black.
- 💬 **Инлайн-комментарии с формой ответа**:
  - Комментарии плавно выезжают вниз прямо под публикацией.
  - Поле ввода для отправки сообщений в Telegram прямо из стены.
- ⚡ **Ускоренная загрузка (0ms Fast Cache)**:
  - Мгновенный вывод кэшированных постов и аватарок.
- 🧩 **Модульная компонентная архитектура (ES6 Modules & CSS)**.

---

## 🚀 Запуск

Запустите скрипт:
```bash
python run.py
```
или двойным кликом по файлу `start_telegram_x.bat`.

Приложение откроется в браузере по адресу: [http://127.0.0.1:8000](http://127.0.0.1:8000)
