# План работ: идеальная копия Telegram для Android

Эталон: исходники Telegram для Android 12.10.6 (`DrKLO/Telegram`) и скриншоты реального приложения (в разговоре, 16 экранов). Всё, что не совпадает с эталоном — дефект.

## Порядок (сначала копия, потом функции)
1. **Эталон под рукой.** Клон `DrKLO/Telegram` (вне репозитория): размеры из `res/values/dimens.xml`, раскладки `res/layout`, строки `res/values-ru/strings.xml`, цвета `Theme.java`, порядок и подписи пунктов меню из `SettingsActivity`, `ProfileActivity`, `DialogsActivity`, `ChatActivity`.
2. **Экраны по скриншотам** (каждый: замер → вёрстка → иконки из оригинала → тест → сравнение рядом):
   1. Настройки: шапка с фото и значком камеры, «Аккаунты», полный список пунктов в порядке оригинала.
   2. Список чатов: аватары историй в шапке, поиск, папки, архив, строки чатов.
   3. Контакты: «Пригласить друзей», «Недавние звонки», сортировка по времени захода, кнопка добавления.
   4. Профиль пользователя: вкладки «Медиа/Файлы/Ссылки/Музыка», кнопки «Чат/Звук/Звонок/Видео», «Добавить в контакты», «О себе».
   5. Профиль канала: шапка с обложкой, кнопки, «Реклама/сотрудничество», вкладки «Подарки/Медиа/Файлы/Ссылки».
   6. Переписка: закреплённое, пузыри (просмотры, реакции), композер, меню бота и список команд, кружки, кнопка «Принять участие».
   7. Просмотр медиа: шапка «имя / дата», «N из M», пересылка, меню.
   8. Меню ⋮ канала и чата.
3. **Поведение**: нажатия, долгие нажатия, свайпы, анимации каждого экрана — по исходникам (`ActionBarMenuItem`, `ChatActivity.createMenu`, `DialogsActivity`).
4. **Функции** (после копирования): режим призрака (готово), сохранение удалённых (готово), локальный Premium (готово, оформление), **моды** как в TeleX.
5. **Ролики, сборка, релиз, документация.**
