# Точность копии

Как сверять клиент с Telegram для Android и что уже измерено.

## Метод
1. Скриншот оригинала (телефон, ширина кадра W пикселей, масштаб экрана S, например 909 px и 2.5×).
2. Скриншот клиента: окно шириной `W / S` CSS-пикселей и `deviceScaleFactor = S` (Playwright), тот же чат, та же тема.
3. Рядом на одной картинке; расхождения правим в `css/chat.css`.
4. Цвета снимаем пипеткой (canvas `getImageData`) прямо со скриншота оригинала.

## Измеренные значения (Android, тёмная тема)
| Элемент | Значение |
|---|---|
| Кнопки шапки | 44 px, зазор 6 px; капсула «имя» 44 px, аватар 42 px |
| Поле ввода | капсула 44 px, кнопка 40 px внутри правого края, текст 18 px |
| Пузырь | поля до края экрана 11 px, внутренние отступы 7/10 px, текст 16 px / 1.18 |
| Интервалы | 3 px внутри серии, 8 px между сериями |
| Углы | 17 px, у хвоста 0, «внутренние» углы серии 6 px |
| Входящий фон | `#202022`; исходящий — градиент темы чата (по умолчанию `#5a86c4 → #568fc3`) |
| Время | 12 px, 45 % белого; в исходящих 85 % |
| Стекло | blur 18 px, saturate 190 %, светлая кромка 0.6 px, внутренний блик |

## Что не воспроизводится в вебе
Преломление фона на краях «жидкого стекла» (нужен шейдер); приближение сделано CSS-размытием и бликами.
