# Promo materials / Промо-материалы TeleX

| Папка | Что |
|---|---|
| `videos/` | Готовые ролики: `vertical` 1080×1920 (TikTok / Shorts / Reels) и `youtube` 1920×1080, на `en` и `ru`. Звук — только эффекты, музыку добавляй сам |
| `logo/` | Доработанный логотип: квадрат 1080 (аватарка), круг, SVG |
| `icons-options/` | Варианты иконки (A–D) и лист сравнения |
| `screenshots/` | Скриншоты интерфейса на demo-данных (ru/en), для постов и сайта |
| `TEXTS.md` | Описания аккаунтов TikTok/YouTube, названия и описания роликов, хэштеги |

Фото в демо — свободные (Unsplash через picsum.photos), аватарки — DiceBear «lorelei» (CC0). Исходники генерации — в папке `promo/` репозитория (`npm`-скриптов нет, см. `promo/render-all.sh`).
