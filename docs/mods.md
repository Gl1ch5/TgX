# Моды TeleX

Мод — расширение, которое работает внутри приложения с **полным доступом** к его API (песочницы нет сознательно).
Поэтому установщик показывает предупреждение, а поле `manifest.verified` зарезервировано под будущую проверку модов.
Моды ставятся в **Настройки → Моды** (или из «Настроек чатов» → «Моды тем»): из файла `.module`, по ссылке `https://…` или вставкой текста.

## Файл `.module`

Мод — файл с расширением **`.module`**. Это обычный текст, внутри может быть что угодно: HTML, JS, CSS, тема, JSON-данные.
Поддерживаются две формы.

**1. JSON-пакет** — несколько частей в одном файле:

```json
{
  "manifest": { "id": "my-mod", "name": "Мой мод", "version": "1.0.0", "author": "me",
                "description": "коротко", "about": "подробно\nв несколько строк",
                "icon": "clock", "preview": ["https://…/1.png", "data:image/png;base64,…"], "tags": ["theme"],
                "settings": [ { "key": "seconds", "type": "switch", "title": "Секунды", "default": false } ] },
  "parts": [
    { "type": "theme", "data": { … } },
    { "type": "css",   "code": "…" },
    { "type": "html",  "code": "<div>…</div><script>…</script>" },
    { "type": "js",    "code": "export default function (tx) { … }" },
    { "type": "json",  "name": "table", "data": { … } }
  ]
}
```

**2. Один исходник с аннотацией** — первая строка-комментарий с `@manifest {json}`, остальное — тело. Тело, начинающееся с `<`, —
HTML (скрипты внутри выполняются), JSON с ключами темы — тема, иначе — JS-модуль. Примеры: `// @manifest {…}`, `<!-- @manifest {…} -->`.

**3. Один большой файл с секциями** — после строки `@manifest` каждая часть начинается строкой-комментарием
`@part js|css|html|theme|json|text [имя]` (`// @part css`, `/* @part js */`, `<!-- @part html -->`). Так в одном файле умещаются стили, разметка и код.

`id` — латиница/цифры/`._-`, 2–41 символ. Размер — до 1,5 МБ. Мод только из `theme`/`css` не исполняет код, поэтому ставится без предупреждения о полном доступе.

### Языки

Любой текст манифеста — `name`, `description`, `about`, `title`/`sub`/подписи `options` в настройках — можно задать либо строкой,
либо по языкам: `{ "ru": "…", "en": "…", "es": "…", "pt": "…", "uk": "…" }`. Берётся язык приложения, иначе английский.
В коде: `tx.L({ ru: '…', en: '…' })`. Официальные моды переведены на все 5 языков.

### Иконка

`icon` — эмодзи **или** картинка: `data:image/svg+xml;base64,…`, `https://…` либо путь внутри приложения (`mods/icons/<id>.svg` у официальных).
Лучше SVG 96×96 со скруглённым квадратом и градиентом — как у официальных модов (`app/static/mods/icons/`).

### Карточка и страница мода

`description` — короткое описание на карточке, `about` — подробное (на странице мода), `preview` — картинка или список картинок
(`https://` или `data:image/…`; без них рисуется превью темы или `icon` на градиенте), `tags`, `author`, `version`.

### Настройки мода

`manifest.settings` — схема: `{ key, type: "switch" | "text" | "number" | "select" | "color", title, sub?, default, min?, max?, options? }`.
Страница мода рисует для них элементы сама. В коде: `tx.config.get(key)`, `tx.config.set(key, v)`, `tx.config.on(key | '*', fn)`;
для собственного блока на странице — `tx.config.render((box) => { … })`. В HTML-частях объект доступен как `TeleXMods['<id>']`.

## Тема (`theme`-часть)

| поле | что делает |
|---|---|
| `vars` | CSS-переменные: `{ "all": {}, "dark": {}, "light": {} }`, например `--tx-bg`, `--tx-accent`, `--tx-bubble-out`, `--tx-surface`, `--tx-text` (список — `app/static/css/tx/tokens.css`) |
| `css` | произвольный CSS |
| `wallpapers[]` | обои в выбор: `{ id, name, kind: "fill" \| "pattern", colors: ["#rrggbb"…], rotation, intensity, url? }` (как у обоев Telegram: 1–4 цвета; `intensity < 0` — тёмный фон; `url` паттерна — svg) |
| `colorThemes[]` | цветовая тема в карусели «Настроек чатов»: `{ id, emoji, accent?, out: { dark: [цвета], light: [цвета] }, wallpapers: { dark, light } }` — у темы свои обои для дня и ночи |
| `apply` | id цветовой темы, которую выбрать сразу после установки |

## API кода (`tx`)

`export default function (tx) { … }` (в HTML-частях — `TeleXMods['<id>']`).

| что | зачем |
|---|---|
| `tx.theme` | `setVars(vars, mode)`, `addCss(css)`, `addColorTheme(theme)`, `addWallpaper(wp)`, `setWallpaper(id)`, `select(themeId)`, `mode()` |
| `tx.ui` | `watch(selector, fn)` — fn(el) для существующих и будущих элементов; `inject(selector, html, where)` — вставить разметку в любой экран; `root()` |
| `tx.ext` | `addMenu(point, provider)`, `addHook(name, fn)`, `on(event, fn)` — см. «Точки расширения» |
| `tx.settings` | `addRow({ title, sub, icon, color, run })`, `addPage({ id, title, sub, icon, render(box) })` — свой экран в настройках |
| `tx.config` | настройки мода: `get`, `set`, `on(key \| '*', fn)`, `render(fn(box))` |
| `tx.storage` | `get(k)`, `set(k, v)` — произвольные данные мода |
| `tx.onStop(fn)` | своя очистка (таймеры, узлы) при выключении мода |
| `tx.data` | части `json`/`text` из пакета, по `name` |
| `tx.S`, `tx.api` | состояние приложения (`S.posts`, `S.channels`, `S.user`) и весь доступ к Telegram |
| `tx.t`, `tx.toast`, `tx.confirm`, `tx.escapeHtml` | перевод, всплывашка, диалог, экранирование |

### Точки расширения (`tx.ext`)

- меню `post` — пункты меню поста: провайдер получает `{ post }` и возвращает `[{ label, icon, run }]`;
- меню `settings` — строки на экране настроек;
- хук `postText` (синхронный) — готовый HTML текста поста → HTML;
- события `view` (сменился экран).

Так как это веб-приложение, мод может и **напрямую менять DOM** любого экрана (`tx.ui.watch`) — это и есть «внедрить что угодно».
Всё, что мод добавил (стили, переменные, темы, обои, меню, наблюдатели, HTML, вставки), снимается при выключении или удалении.

## Скин: переделать весь интерфейс одними переменными

Слой `css/tx/skin.css` выключен, пока на `<html>` нет класса `tx-skin`. Мод включает его вызовом `tx.theme.setSkin(tokens, mode)`
(или частью темы `skin`), и все основные поверхности приложения начинают рисоваться из токенов `--sk-*` — в дневном и ночном режиме.
Знать имена классов не нужно.

| токен | что красит |
|---|---|
| `--sk-card-bg` `-border` `-shadow` `-filter` `-radius` | карточки: группы настроек, пузыри постов и сообщений |
| `--sk-bubble-in` `--sk-bubble-out` `--sk-bubble-radius` | входящие / исходящие пузыри |
| `--sk-bar-bg` `-border` `-shadow` `-filter` `-radius` | нижняя панель, поиск, вкладки, «пилюли» шапки, поле ввода |
| `--sk-menu-bg` `-border` `-shadow` `-filter` `-radius` | контекстные меню, полоса реакций |
| `--sk-dialog-bg` `--sk-dialog-radius` | диалоги |
| `--sk-button-bg` `--sk-button-text` `--sk-button-radius` | кнопки |
| `--sk-chip-bg` `--sk-chip-radius` | реакции, плашка активной вкладки, теги |
| `--sk-highlight` | светлая кромка сверху у всех поверхностей (внутренняя тень) |
| `--sk-overlay`, `--sk-separator`, `--sk-field-bg` | затемнение под меню/диалогами, разделители, поля ввода |

Акцентный цвет всего приложения — `tx.theme.setAccent('#0a84ff', '#007aff')` (второй — для дня) или поле `accent`/`accentDay` в части темы.
Базовые токены цвета (`--tx-bg`, `--tx-surface`, `--tx-text`, `--tx-accent*` …) — в `css/tx/tokens.css`.

## Поверхности, которые можно менять напрямую

Если токенов мало — стилизуйте классы (мод-CSS подключается последним и перебивает стили приложения при равной специфичности):
`.tx-dock` (нижняя панель), `.tx-glass` (пилюли шапки), `.tx-search-main`, `.tx-tabs`, `.tx-bubble` / `.tx-bubble.is-out` (пост, сообщение),
`.tx-group` / `.tx-row` (настройки), `.tx-menu`, `.tx-ctx-reactions`, `.tx-dialog`, `.tx-btn`, `.tx-reaction`, `.tx-mainbar` (верхняя панель ленты),
`.tx-titlebar`, `.tx-mod-card`. Экраны: `#screen-wall`, `#screen-settings`, `#screen-profile`, `#screen-thread`, `#screen-channel`.

## Куда что вставлять (слоты)

`tx.ui.add(слот, { id, title?, icon?, run?, html?, el?, render?(host, ctx), position? })` — вставка в именованное место интерфейса; снимается при выключении мода.

| слот | где | что вставлять |
|---|---|---|
| `dock` | нижняя панель | кнопка-вкладка |
| `topbar` | верхняя панель ленты (рядом с «TeleX» и меню) | кнопка или виджет |
| `search` | внутри поля поиска | кнопка (фильтр, голос…) |
| `tabs` | вкладки ленты (Все · Медиа · …) | ещё одна вкладка |
| `fab` | плавающая круглая кнопка | кнопка |
| `post.header` | рядом с названием канала в посте | значок, бейдж |
| `post.footer` | под текстом поста | блок (статистика, перевод, заметка) |
| `post.actions` | рядом с кнопкой «поделиться» | кнопка |

Остальное: пункт в меню поста — `tx.ext.addMenu('post', …)`; строка/страница в настройках — `tx.settings.addRow/addPage`; свой экран — `tx.ui.openScreen`;
текст постов — хук `postText`; реакция на каждый пост — `tx.ui.onPost`; внешний вид — `tx.theme.*`. Пример со всеми слотами: `mods-examples/slots-demo.module`.

### Виды модов

Тема (без кода) · виджет (часы, погода, счётчик) · кнопка-инструмент · улучшение постов · фильтр (скрыть по словам/каналам) · своя страница (статистика, блокнот).

## Новые экраны и кнопки

- `tx.ui.openScreen({ title, render(box, { close }) })` — свой полноэкранный экран; жест «назад» закрывает его.
- `tx.ui.addDockItem({ id, title, icon, run })` — кнопка в нижней панели (`icon` — эмодзи, SVG-разметка или имя иконки).
- `tx.settings.addPage(...)` — свой экран внутри настроек.
- `tx.ui.onPost((el, post) => …)` — для каждой карточки поста, сейчас и при появлении новых; событие `post` для `tx.ext.on`.
- `tx.app` — `openChannel(id)`, `openThread(postId)`, `setView('wall'|'settings'|'profile')`, `openSettings(page)`, `reloadFeed()`, `lang()`, `theme()`.

## Жизненный цикл

Мод запускается при старте приложения, если включён. Всё, что он зарегистрировал через `tx`, снимается при выключении/удалении;
свои таймеры и слушатели снимайте в `tx.onStop`. Официальные моды из каталога **обновляются сами** при выходе новой версии (настройки мода сохраняются).
Обновление чужого мода — переустановка файла с тем же `id`.

## Мод с помощью нейросети

В **Настройки → Моды** внизу: «Скопировать промпт для нейросети» → вставьте его в нейросеть и допишите, какой мод нужен → скопируйте ответ →
«Вставить мод из буфера». Промпт содержит всю спецификацию и жёсткие правила вывода (только файл, без пояснений).

## Публикация для всех (сообщество)

Положите `<id>.module` в `community/mods/` через Pull Request — после проверки CI мод появится в приложении у всех (Настройки → Моды → Сообщество).
Правила — в [`community/README.md`](https://github.com/Gl1ch5/TgX/tree/main/community).

## Свой мод в каталоге

1. Положите файл `<id>.module` в `app/static/mods/` и SVG-иконку в `app/static/mods/icons/<id>.svg`.
2. Добавьте запись в `app/static/mods/catalog.json`: `{ id, file, name, version, author, icon, description, tags }` (`name`/`description` — по языкам).
3. Поднимите `version`, когда меняете мод — у пользователей он обновится сам. Мод из каталога получает значок проверенного.

## Советы

- Делайте мод работающим в обеих темах: используйте токены, а не жёсткие цвета; проверяйте в `?` дневном и ночном режимах.
- Все тексты — на 5 языков (`{ru,en,es,pt,uk}`), иконка — SVG 96×96.
- Не полагайтесь на то, что узел DOM живёт долго: интерфейс перерисовывается — используйте `tx.ui.watch` / `tx.ui.onPost`.
- Не делайте тяжёлых вычислений при каждой прокрутке: экраны телефонов слабее, чем ваш компьютер.

Примеры — [`mods-examples/`](../mods-examples). Для нейросетей — [`docs/mods-for-agents.md`](mods-for-agents.md).


## ИИ в модах (`tx.ai`)

В TeleX есть встроенный ИИ. Мод может пользоваться им **без собственного ключа**: в манифесте указывается `"permissions": ["ai"]`, а в коде вызывается `tx.ai`.
Пользователь один раз вставляет бесплатный ключ Groq (Настройки → Ключ Groq), а при установке мода видит, что мод использует ИИ.

| Вызов | Что делает |
|---|---|
| `tx.ai.available()` | `true`, если в манифесте есть право `ai` и ключ сохранён |
| `await tx.ai.ask('запрос', { system, json, maxTokens, temperature })` | один вопрос → строка |
| `await tx.ai.chat([{ role: 'user', content: '…' }, …], opts)` | диалог → строка (объект при `json: true`) |
| `tx.lang()` | язык приложения: `ru`, `en`, `es`, `pt`, `uk` |

Лимиты: не больше 12 запросов в минуту на мод, до 12 000 символов в сообщении, до 2 000 токенов ответа, последние 24 сообщения. Модель маленькая и быстрая — просите короткие ответы и не отправляйте секреты.
Ошибки приходят исключением (`e.message` читаем для человека, `e.code` — `no-key`, `limit` или `key`): ловите их через `.catch` и показывайте сообщение.
Мод может подключить и **свой** ИИ-сервис с собственным ключом (поле `settings` типа `text`), но лучше использовать `tx.ai`.

Готовые примеры — официальные моды «ИИ-чат» и «Переводчик постов» (`app/static/mods/ai-chat.module`, `ai-translate.module`).

## Проверка модов ИИ перед установкой

Если добавлен ключ Groq, при установке мод проверяется ИИ: он ищет опасный код (отправка данных наружу, `eval`, чтение сессии) и то, что ломает интерфейс (элементы поверх статус-бара, скрытие панелей, глобальные селекторы). Результат — «проблем не найдено», «есть замечания» или «опасный код» — виден в окне установки. Это подсказка, а не гарантия: ставьте только моды, которым доверяете. Проверку можно отключить в Настройки → Ключ Groq.


## Новые возможности API

| Что нужно | Как |
|---|---|
| пост уже отрисован (замерить высоту, свернуть) | `tx.ui.onPostRendered((el, post, { height }) => …)` — приходит через два кадра после появления карточки |
| текст поста | `tx.ui.onPostText((textEl, post, card) => …)` или слот `post.text` (`position: 'start'` — перед текстом) |
| смена темы | `tx.theme.on('change', (palette) => …)`, `tx.theme.palette()` — актуальные цвета (для канваса) |
| пункт меню поста с галочкой и подменю | `tx.ext.addMenu('post', ({ post }) => [{ label, icon, run, checked, items }])` |
| тост с кнопкой «Отмена» | `tx.toast('Скрыто', { action: 'Отмена', run: () => … })` |
| горячие клавиши | `tx.keys.add('mod+shift+c', fn)` — снимаются вместе с модом, не срабатывают при вводе текста |
| погода / частицы / фоновая анимация | `tx.ambient.add({ id, draw(ctx, w, h, dtMs, palette) })` — один общий холст и один цикл (≤ 30 кадров/с) на все моды. Свой полноэкранный canvas и свой `requestAnimationFrame` создавать не нужно |
| медиа поста | `tx.media.of(post)` → `[{ type, url, thumb, duration, size }]`, `tx.media.urls(post)` |
| список каналов в настройках мода | поле `{ "type": "channels" }` (массив id) или `{ "type": "select", "optionsFrom": "channels" }` (один id) |
| конфликты | `"conflicts": ["id-другого-мода"]` в манифесте — при установке показывается предупреждение |
| наборы модов | `presets` в `mods/catalog.json` — одна кнопка ставит сразу несколько официальных модов («Зимний набор», «ИИ», «Читатель») |

Примеры: официальные моды «Снегопад» (`tx.ambient`), «Читать позже» (меню с галочкой, тост с «Отмена», страница в настройках), «Свернуть длинные посты» (`onPostText`).
