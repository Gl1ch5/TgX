# Пакет для агента: «полный клиент Telegram в вебе» (форк TeleX)

Это набор файлов, чтобы другой ИИ-агент (например, Gemini Flash) смог **с нуля понять проект и вести разработку по плану**, не ломая то, что уже работает. Агенту нужно давать задачи **маленькими кусками** — он слабее, поэтому всё здесь написано максимально явно.

## Что внутри

| Файл | Кому | Что это |
|---|---|---|
| `01-MASTER-PROMPT.md` | агенту, **первым сообщением** | Роль, цель, правила работы, порядок действий |
| `02-AGENT-RULES.md` | агенту, **как постоянные правила** | Положить в корень форка как `AGENT.md` (и скопировать в `GEMINI.md`/`CLAUDE.md`, если инструмент читает такой файл) |
| `03-ARCHITECTURE.md` | агенту | Как устроен текущий код (карта файлов, потоки данных, паттерны) |
| `04-PLAN.md` | агенту и тебе | План по этапам с критериями приёмки |
| `05-PHASE-PROMPTS.md` | тебе | Готовые промты: по одному на этап/задачу — вставляешь по очереди |
| `06-TELEGRAM-API-NOTES.md` | агенту | Шпаргалка по Telegram API/GramJS и грабли, на которые уже наступили |
| `07-TESTING.md` | агенту и тебе | Как проверять работу без живого аккаунта и что смотреть глазами |

## Как запускать (по шагам)

1. **Форк**: на GitHub нажми *Fork* у `Gl1ch5/TgX`. Сними галочку «Copy the `main` branch only», чтобы взялась и ветка с последним кодом (`ccr-297b0b47-05qrmt`), либо в форке сделай её основной. Версия кода должна быть **3.13.0 или новее** (проверь `app/static/js/version.js`).
2. Эта папка `docs/full-client/` приедет вместе с форком. Скопируй `02-AGENT-RULES.md` в корень форка как `AGENT.md` (старый `AGENT.md` — документ про TeleX, его можно оставить как `docs/teleX-AGENT-old.md`).
3. **Свой `api_id`**: зайди на https://my.telegram.org → *API development tools* → создай приложение и впиши `API_ID`/`API_HASH` в `app/static/js/telegram.js` (константы вверху). Использовать чужие ключи в публичном форке нельзя.
4. **Реши вопрос с лицензией** (см. ниже) *до* того, как агент начнёт что-то копировать.
5. Открой сессию агента **в корне форка** и отправь `01-MASTER-PROMPT.md` целиком. Дождись, пока он прочитает документы и напишет свой план — **проверь план**, поправь, только потом пускай писать код.
6. Дальше — по этапам из `05-PHASE-PROMPTS.md`: один этап = одна сессия (или одна ветка). После каждого этапа — проверка по чек-листу из `07-TESTING.md` (его минимум: `npm test` зелёный + скриншоты на телефонной ширине, светлая и тёмная тема).
7. Если агент «поплыл» (ломает старое, переписывает всё, придумывает API): остановить, открыть **новую сессию**, дать только `01-MASTER-PROMPT.md` + текущую задачу и сказать «не трогай ничего вне указанных файлов».

## Лицензия — важное решение

* **Web A** (`Ajaxy/telegram-tt`) и **Web K** (`morethanwords/tweb`) — под **GPL-3.0**. Если агент копирует оттуда код, весь форк обязан стать GPL-3.0 (с открытым исходным кодом).
* Нынешний TeleX — **MIT**. Рекомендация: **не копировать** код из Web A/K, а переписывать самим (смотреть на них как на справочник поведения). Это и есть правило по умолчанию в `02-AGENT-RULES.md`. Если решишь идти на GPL — скажи агенту явно и поменяй `LICENSE`.
* Официальные клиенты (Android/iOS/Desktop) тоже GPL; из них брали только **ресурсы-иконки** для стилистики — это уже сделано в `tools/icons`.

## Правила Telegram для сторонних клиентов (коротко)

Свой `api_id`; не отключать рекламу в каналах-спонсорах нечестными способами; не рассылать спам и не автоматизировать массовые действия; уважать лимиты (FLOOD_WAIT); не выдавать клиент за официальный. Агент обязан соблюдать это — см. `02-AGENT-RULES.md`.

## Что ты проверяешь сам после каждого этапа (5 минут)

1. `npm install && npm test` — зелёный.
2. Открой `npm run serve` → http://localhost:8765/ на телефонной ширине (DevTools, 390×844). Пройди новые экраны в **тёмной и светлой** теме и на **английском** языке.
3. Посмотри `git diff --stat`: изменения должны быть только в тех файлах, что перечислены в задаче.
4. Пересчитай: появились ли новые русские строки **без** `t('…')`? (`npm run i18n` падает, если строка не переведена.)
