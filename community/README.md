# Моды сообщества / Community mods

Здесь живут моды, которые написали пользователи. Они появляются в приложении: **Настройки → Моды → Сообщество**.
Проект их не проверяет (у них нет значка «проверено»): пользователь видит предупреждение перед установкой.

This folder is the registry of community mods. They show up in the app under **Settings → Mods → Community**.
They are not reviewed by the project (no "verified" mark); the user sees a warning before installing.

## Как опубликовать мод / How to publish

1. Сделайте мод — файл `<id>.module` ([формат](../docs/mods.md); нейросеть соберёт его по [инструкции](../docs/mods-for-agents.md), в приложении есть кнопка «Скопировать промпт»).
2. Форкните репозиторий и положите файл в `community/mods/<id>.module` (имя файла = `manifest.id`).
3. Проверьте локально: `node tools/community.mjs --check`.
4. Откройте Pull Request. CI проверит файл; после слияния сайт пересоберётся и мод появится у всех (через несколько минут).
5. Новая версия — тот же файл с большим `manifest.version`: у пользователей появится кнопка «Обновить».

## Требования / Rules (проверяет CI)

- `manifest.id` — `[a-z0-9][a-z0-9._-]{1,40}` и равен имени файла; `name`, `description`, `author`, `version` (`1.2.3`) обязательны.
- Тексты лучше сразу на 5 языков (`{ru,en,es,pt,uk}`) — иначе будет предупреждение.
- `icon` — эмодзи, `data:image/…` или `https://…`. Поля `verified` и `official` зарезервированы за проектом.
- JS-часть: `export default function (tx) { … }`. Размер файла до 1,5 МБ.
- Мод не трогает сессию Telegram и не отправляет данные пользователя на сторонние сервера без явного описания в PR.
- Мод должен нормально работать в светлой и тёмной теме и на телефоне; свои таймеры и слушатели снимайте в `tx.onStop`.

## Как это устроено / How it works

`tools/community.mjs` проверяет все файлы и собирает `app/static/community/index.json` и копии модов; запускается при каждой сборке сайта
(`.github/workflows/pages.yml`). Приложение читает `community/index.json` рядом с собой и ставит файлы оттуда. Свой отдельный репозиторий
подключить просто: скопируйте эту папку и `tools/community.mjs`, в приложении поменяйте адрес индекса.
