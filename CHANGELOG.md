# TeleX 1.0 beta

TeleX собирает посты всех Telegram-каналов в одну ленту. Версия 1.0 beta — первая публичная: ниже всё, что в ней есть.

## Лента и чтение

- Одна стена из всех каналов: истории, комментарии, реакции, премиум-эмодзи, закладки.
- Вкладки «Все», «Медиа», «Популярное», «Избранное» с анимированным индикатором; переключаются свайпом влево и вправо, во время загрузки нажатие не теряется.
- Меню поста как в Telegram: ответить, копировать текст и ссылку, сохранить в галерею, переслать в «Избранное», в закладки, открыть в Telegram.
- «Не показывать канал в ленте» — канал пропадает со стены, не отписывая вас; вернуть можно в Настройки → Стена.
- Экран канала, закрепы, комментарии, просмотр фото и видео, истории.
- Силуэты постов: пока лента грузится, на экране сразу видны заготовки карточек, а не пустота.
- Бесконечная лента с приоритетной загрузкой медиа, чтобы быстрая прокрутка не тормозила.

## Оформление

- Обои и цветные темы чатов из оригинального Telegram, в том числе в режимах день/ночь.
- Светлая тема по настройке телефона, тёмная, ручной выбор.
- Настройки в стиле Telegram Android: цветные иконки, группы, переключатели, плавные переходы.
- Иконки интерфейса — оригинальный набор Telegram.
- 5 языков: русский, английский, испанский, португальский, украинский. Проверка сборки не пропускает непереведённые строки.
- Все диалоги в стиле Telegram (иконка, заголовок, кнопки капсом); браузерные окна подтверждения убраны.
- В интерфейсе нет эмодзи: только иконки Telegram.

## Скорость запуска

- Файлы приложения упакованы внутрь Android-приложения и Windows-версии, сеть для запуска не нужна.
- Service Worker заранее кэширует все файлы; обновление подхватывается по хешу сборки.
- Стили загружаются параллельно, модули — с предзагрузкой, тяжёлый Tailwind не блокирует первый кадр. В тестовой среде с задержкой сети первый кадр с силуэтами стал появляться за 352 мс вместо 646 мс.

## Android и Windows

- Автообновление Android в стиле Telegram: окно «Доступно обновление», загрузка в фоне, установка через системный установщик, вход в Telegram сохраняется.
- Проверка обновлений при запуске, при возврате в приложение (не чаще раза в минуту) и каждые 3 минуты, с повторами при отсутствии сети; статус и ручная проверка в «О TeleX».
- Новая иконка приложения.
- Windows: установщик и портативная версия, уведомление о новой версии.
- Сборки публикуются в GitHub Releases; отдельный ручной запуск создаёт релиз с тегом.

## Моды

Свой формат `.module`: один файл с манифестом и частями (код, стили, разметка, тема, данные). Три формы записи: JSON-пакет, исходник с комментарием `@manifest`, файл с секциями `@part`.

**Возможности мода**
- Темы: цвета, обои, цветные темы чатов, токены «скина» — единый слой для карточек, панелей, меню, диалогов, кнопок.
- Слоты интерфейса: верхняя панель, поиск, вкладки, нижняя панель, плавающая кнопка, шапка, текст, низ и действия поста.
- Пункты меню поста с галочкой и подменю, страницы настроек, полноэкранные страницы с шапкой и режимом чата.
- События: пост отрисован, текст поста, смена темы с актуальной палитрой.
- Тосты с кнопкой «Отмена», горячие клавиши, помощник по медиа поста.
- Общий слой для фоновых анимаций: один холст и один цикл на все визуальные моды (снег, дождь, звёзды).
- Настройки мода: переключатель, число, список, цвет, текст, выбор канала или нескольких каналов.
- Права и конфликты в манифесте; тексты манифеста на 5 языках; иконки — имена иконок Telegram, SVG или картинка.

**ИИ для модов**
- `tx.ai` даёт модам встроенный ИИ через бесплатный ключ Groq пользователя; мод объявляет право `ai`, диалог установки об этом сообщает.
- Ответы можно получать потоком; лимит — 12 запросов в минуту на мод.

**Официальные моды**
- «Жидкое стекло» — реальное преломление, хроматическая аберрация, блики.
- «Аврора» — цветовые темы с обоями для дня и ночи.
- «Компактная лента», «Время чтения», «Часы».
- «ИИ-помощник» — чат в стиле Telegram, ответы пишутся на лету, подсказки, код, списки, копирование.
- «Переводчик постов» — перевод потоком, выбор языка, копирование.
- «Снегопад» — три слоя глубины, ветер, цвет следует за темой.
- «Читать позже» — пункт меню с галочкой, метка на карточке, список в настройках, «Отмена» в тосте.
- «Свернуть длинные посты».
- Наборы модов одной кнопкой: «Зимний», «ИИ», «Читатель»; у каждого набора своя страница.

**Безопасность и надёжность**
- Мод, который не запустился, не остаётся в приложении: вам показывается причина.
- Аварийная кнопка «Отключить все моды» в меню ⋮; если приложение два раза подряд не запустилось, моды отключаются автоматически; ручной вход в безопасный режим через `?safe=1`.
- Если указан ключ Groq, перед установкой мод проверяется ИИ: утечки данных, `eval`, чтение сессии, элементы поверх статус-бара, скрытие панелей. Проверка — подсказка, не гарантия.
- Метку «проверен» получают только официальные моды проекта.

**Документация**
- Страница https://telex-web.ru/mods.html для людей и отдельная подробная инструкция для нейросетей: слоты, цвета и токены с реальными значениями, карта слоёв, правила безопасных отступов, готовые рецепты, чек-лист. Та же инструкция копируется в приложении одной кнопкой («Скопировать промпт»), ответ нейросети ставится кнопкой «Вставить мод из буфера».

## Каталог модов и публикация

- Вкладки: «Главная» (рекомендации, наборы, категории, популярное, новинки), «Каталог» (поиск, категории), «Мои», «Создать».
- Страницы модов в едином виде: крупная иконка, плитки «Тип», «Версия», «Источник», описание, настройки, переключатель.
- Моды сообщества: оценка звёздами, лайки, счётчик установок, жалобы.
- Публикация своего мода прямо из приложения, без GitHub; автор определяется секретом на устройстве, перезаписать чужой мод нельзя.
- Свайп между вкладками, мгновенное переключение (перерисовывается только содержимое).
- Если сервер каталога недоступен, приложение работает с официальным каталогом.

## Первый запуск и ИИ

- После входа в Telegram — окно в стиле Telegram: тема, язык, необязательный ключ Groq.
- Если отказаться от ключа: сначала мягкое объяснение, затем красное предупреждение со списком преимуществ, затем больше не спрашивает. При выходе из аккаунта всё сбрасывается.
- Ключ хранится только на устройстве и отправляется только в Groq; управление в Настройки → Ключ Groq.

## Сервер

- Своё API каталога: публикация, поиск, категории, лайки, оценки, скачивания, рекомендации. Без зависимостей, данные в одном файле.
- Файлы, читающие сессию Telegram или секреты приложения, отклоняются; `eval`, удалённые скрипты и внешние запросы отмечаются; три жалобы скрывают мод; ограничения по частоте.
- Скрипт установки и таймер: сервер сам проверяет GitHub каждые 5 минут, тестирует новый код и обновляется.
- Счётчик пользователей: приложение раз в сутки отправляет случайный номер установки (без аккаунта и данных), в «О TeleX» это можно отключить; на сайте показывается число активных за неделю и установок всего.

## Известные ограничения

- Бета: возможны ошибки, в том числе на телефонах, на которых я приложение не проверял.
- Неофициальный клиент; личных чатов нет, это лента каналов.
- «Жидкое стекло» работает только в браузерах на Chromium (Android WebView, Chrome, Edge).
- Windows-версия без подписи: SmartScreen предупредит. Android — установка из неизвестных источников.
- Каталог сообщества в начале пустой. Если сервер недоступен, на «Главной» остаются наборы и официальные моды.
- Проверка модов ИИ — только подсказка; ставьте моды, которым доверяете.
